# 隐私与发布检查

本包在主机内部连接已有的 Codex 私有 socket。运行配置只保存在本地 `.bridge-state/`；其中的安装备份可能包含原有 Paseo 配置，请当作私有资料保管。

会话发现依赖读取原生会话元数据；消息仍通过原生 daemon 传递。同步器会在 Paseo 数据目录保存会话映射、标题和归档状态，以判断下一次变更方向。它不会把这些内容上传到 GitHub，也没有遥测服务。

发布文件使用白名单：通用源码、兼容补丁、测试、文档和许可证。运行配置、备份、聊天记录、日志、依赖目录和 Python 编译缓存均不应进入发行包。

发布流程检查源码与完整 Git 历史中的常见凭据，并解包检查最终资产；另检查环境专属路径、主机地址和真实会话标识。自动扫描不能覆盖所有秘密格式，提交 Issue 或自行发布修改版前仍需检查文件内容。

请不要在 Issue 中粘贴 `.bridge-state/`、完整配置、Codex home、Paseo 数据目录或真实聊天日志。
