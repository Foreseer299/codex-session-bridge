# 隐私与发布检查

插件在主机内部连接已有的 Codex 私有 Unix socket，不给 Codex 新开公网监听，也没有遥测服务。Paseo 与 ChatGPT 各自的连接机制、账号和隐私设置仍然适用。

## 本机保存什么

原生插件的运行文件和安装状态放在 Paseo home 下：

```text
plugin-state/codex-session-bridge/runtime/
  .bridge-state/
```

该目录包含本机路径、安装记录、运行配置和回退资料。备份可能包含原有 Paseo 配置，请作为私有资料保管，不要上传到 GitHub 或贴进 Issue。v0.1.0 手动版的 `.bridge-state/` 位于旧安装目录中，也应保留同样的保护。

会话发现读取原生会话元数据；消息通过已有 daemon 传递。同步器在 Paseo 数据目录保存会话映射、标题和归档状态，用于判断下一次变更方向。它不会将这些内容上传到本项目或 GitHub。

## 安装和卸载会改变什么

安装在预检通过后开启 Paseo 插件总开关，并自动管理桥接命令及版本锁定的兼容补丁，保留原有权限、模型与无关配置。开启总开关也会启动原先已标记为启用的其他插件。停用或移除时按字段恢复配置、按哈希核对补丁；遇到后来修改过的内容会停止恢复。

卸载保留原生聊天与同步元数据，不把删除插件当成删除聊天。安装备份只是回退资料，不是一份聊天备份。

## 发布前检查什么

发行包采用文件白名单，只包含通用源码、插件入口、兼容补丁、测试、文档和许可证。运行配置、原件备份、聊天、日志与 Python 编译缓存不进入发布包；依赖通过锁文件固定并由安装流程获取。

发布检查覆盖源码、完整 Git 历史和解包后的文件，扫描常见凭据，并核对环境专属路径、主机地址与真实会话标识。自动扫描不能识别所有秘密格式，自行发布修改版或提 Issue 前仍需检查内容。
