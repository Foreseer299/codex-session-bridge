# v0.2.0 验证范围

- 33 项 Python 测试：安装事务、配置字段拥有权、备份恢复、原件/版本校验、状态同步和配置 schema 拒绝。
- 4 项 Node 测试及桥接回归：空闲判断、运行资源保护、包定位、停用状态、会话事件隔离与 Desktop 工具请求隔离。
- 独立 Paseo 0.15.3 实例，从原始 npm 服务端文件开始：Git 来源插件安装、自动开启插件总开关、自动配置和重启、日志进入 ready。
- 停用后所有三个文件恢复原始哈希，插件拥有的配置撤回；重新启用期间立即移除也完成恢复。
- 一键安装入口调用官方插件接口，跨 worker 重启后等待到 ready。

隔离实例使用合成的 Codex Unix socket，未提交真实模型任务，也未复制个人聊天。它验证插件安装与生命周期，不替代用户在自己手机上的双向聊天验收。桥接消息和元数据逻辑沿用 v0.1.0；升级后的客户端仍建议按安装指南做双向接续检查。

公开发行前另外检查 Git 历史及解包内容，排除凭据、真实主机路径、会话记录、运行配置和编译缓存；安装依赖使用固定锁文件并执行 npm audit。
